# Asset Phase placeholders

The native platform hosts currently retain Flutter-generated placeholder artwork
where a compilable host requires it. When the owner explicitly starts the Asset
Phase, replace the Android launcher/adaptive icons, iOS app and launch assets,
macOS icon set, Windows ICO, Linux application icon/desktop packaging artwork,
installer artwork, store screenshots, notification icon, and promotional art.

None of the current generated placeholders is final Loom branding.
