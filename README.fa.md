# لوم

**پیام‌رسانی با چند مسیر تحویل**

نسخهٔ مخزن: `0.3.0-alpha.1` · مجوز: GPLv3-only

[راهنمای کامل فارسی](README.md#persian-home-node-guide) · [English README](README.md) · [کانال تلگرام](https://t.me/LoomMessanger)

</div>

راهنمای فارسی کامل پروژه، شامل معرفی Loom، پیش‌نیازها، نصب Home Node روی VPS
خارج از ایران یا سرور داخل ایران، انتخاب میرورهای Liara و Arvan، تنظیم HTTPS،
فایروال، تماس‌ها، مدیریت نود و عیب‌یابی، در انتهای فایل اصلی README قرار دارد:

**[رفتن به راهنمای کامل فارسی و دستورهای آمادهٔ کپی‌و‌اجرا](README.md#persian-home-node-guide)**

برای نصب سریع، همان‌جا سه دستور مستقل آماده شده است:
- نصب معمولی با منابع اصلی
- نصب با میرور Liara
- نصب با میرور Arvan

> نکته: میرورهای Liara و Arvan فقط منابع مشخصی مثل Docker Hub و بعضی مخازن
> Ubuntu/Debian را پوشش می‌دهند. ایمیج‌های اختصاصی Loom همچنان از GHCR و
> سورس نصب از GitHub دریافت می‌شوند؛ بنابراین این انتخاب به معنی نصب کاملاً
> آفلاین یا پراکسی تمام ترافیک سرور نیست.

این نسخه آلفاست و ممیزی امنیتی مستقل ندارد. پیش از استفادهٔ مهم، محدودیت‌های
رمزنگاری و سازگاری نسخه را در README اصلی بخوانید.
